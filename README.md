# CEN0336_2026_13660999_Python08
Esse repositório contem os scripts, arquivos de saída e arquivos de teste utilizados para resolução do conjunto de problemas do módulo Python 8 - Estruturas de dados. A mensagem de commit indica a qual exercício o script é referente. Todos os códigos possuem comentários que explicam, brevemente, o que está sendo realizado em cada etapa. Além disso, um relatório com explicações mais detalhadas foi enviado no edisciplinas. Os scripts de todos os exercícios possuem a mesma base, ou seja, o início (recebimento, estruturação dos dados, envio para o arquivo de saída etc) e o final (print da mensagem de sucesso) são o mesmo ou muito parecidos. A diferenciação entre eles está na parte do código que resolve o que é pedido exclusivamente em cada questão.
